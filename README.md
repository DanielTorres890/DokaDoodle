# Dokadoodle
Dokadoodle is a multiplayer game where you play against other players in a race to complete map objectives
Imagine board game style movement like Mario Party, but instead of mini games it functions more like a standard RPG with stats, xp/levels, items and classes where you fight NPCS and other players
Heavily Inspired off of Dokapon Kingdom (hence the name similarity I'm not the best at naming things)
# Stack
Utilizes Unity 6 and Unity solutions such as Relay and NGO for all aspects of the game from Multiplayer to saving and loading data
